# 王国之泪 Mod

这里收录王国之泪 1.4.3 的玩法与界面 Mod。各功能按独立安装包发布，玩家可以按需要选择；部分功能需要共享组件或配套资源。

## 功能

| Mod | 功能 |
|---|---|
| 宝箱装备词条 | 为宝箱中的装备生成游戏支持的词条 |
| 料理效果扩展 | 让不同料理增益同时生效，并分别计时 |
| 英雄之路扩容 | 增加英雄之路可记录的足迹容量 |
| 装备目录 | 在背包中浏览装备、查看属性并切换分类 |
| 旅行商人装备目录 | 扩展商人的装备商品与分类 |
| 马匹属性 | 在相机画面中查看马匹属性 |
| 地图标记 | 显示呀哈哈、洞窟、水井与深穴，调整完成标记和缩放显示 |
| 地图高度与收集引导 | 显示目标的高度方向，以及魔犹伊、图纸等收集目标 |
| 便利功能 | 调整耐久、材料与消耗品保留、射箭等行为 |
| 装备融合支持 | 恢复部分装备的原生单材料融合支持 |
| 箭矢轨迹 | 显示预计轨迹和落点；试验版，远距离可能存在偏差 |

## 运行环境

- 游戏版本：1.4.3。
- 当前配置使用 Eden；其他模拟器和 Switch 主机的兼容性未确定。
- WXLM 模块需要兼容的 WiiXLaunch 运行组件。
- 部分功能需要 TSQ 1.15 或专用 GameData、UI、装备资源，具体以各包说明为准。

## 下载与安装

安装包将分别放在 [Releases](https://github.com/wuruoye/TotK-Mods/releases)。目前尚无公开下载版本。

下载所需功能后，解压到游戏的 Mod 目录，保留包内文件夹结构。先安装说明中列出的前置组件，再启用对应功能。修改相同文件或游戏逻辑的 Mod 可能发生冲突，请查看各包的兼容说明。
